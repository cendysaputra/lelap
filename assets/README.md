# LELAP — Level 1 Assets

34 PNG assets for the LELAP side-scrolling platformer, arranged to match the requested runtime paths.

## Included

- UI: title background, logo, button, panel
- Player: idle, two walk frames, jump, hide
- Enemies: pengembara, pengintai, and bayangan state frames
- Props, platforms, tiles, three parallax background layers, and seven decor props

## Notes

- `bg/title.png`, `bg/far.png`, and tiles are opaque images.
- Other gameplay sprites and UI props have transparent backgrounds and have been tightly cropped.
- Background layers are supplied separately as `far`, `mid`, and `near`.
